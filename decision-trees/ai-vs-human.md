# 判断フロー：「AIに任せる」vs「人間が確認」の境界

> [`handbook/04-wp-publish-guide.md`](../handbook/04-wp-publish-guide.md) の「迷ったらAI」原則を補足する判断基準。

---

## 原則

V/ENTER WEB は **「AIに任せて進める」** が基本姿勢。ただし、**人手確認が必須の領域** がある。

---

## カテゴリ別の判断

### ✅ AIに完全に任せてよい（人手確認不要）

- HTML / CSS / JS の実装ドラフト生成
- WP最適化版の作成（4-pre 監査含む）
- Playwright 全自動テスト（5-AI）
- 画像のリサイズ・圧縮・WebP変換
- Lighthouse スコア測定
- コンソールエラー検出
- 文章の校正（誤字脱字・口調の統一）
- 翻訳・要約

### ⚠️ AIに任せて、人手で必ず最終確認する（QC必須）

- **脆弱性スキャンレポート**: 誤検知の二重チェック（櫻井みどり、3-5分/件）
- **デザインのブランド整合**: VAIZO Design Policy 準拠を最終目視
- **コピーライティングの感情・温度**: 軍事比喩・否定列挙等の検出
- **クライアント向けメール**: 道義的ライン違反の検出（恐怖訴求・煽り等）
- **WP統合方式の選定**: AIの推奨を尊重しつつCTOが最終判断
- **公開前の見た目スクショ**: クライアントが認識した最終案と一致するか

### ❌ AIに任せず、必ず人間が実行・判断する

- **クライアントへの送信** (脆弱性レポート添付メール、提案メール、公開報告)
  - 理由: 道義的判断・関係性・タイミング
- **メール宛先のテスト送信受信確認** (5-メール)
  - 理由: クライアントの実機での受信が最終確認
- **クライアントとの口頭コミュニケーション** (会議・電話)
  - 理由: 信頼関係・空気感
- **法的判断** (削除依頼対応・クレーム対応の最終判断)
  - 理由: 顧問弁護士相談を要する領域
- **金額・契約条件の最終決定**
  - 理由: 経営判断
- **業務委託契約の指揮命令性に触れる判断**
  - 理由: 偽装請負の法的リスク
- **個人情報の扱い**
  - 理由: 個人情報保護法・関係法令

## 判断フロー（簡易版）

```
┌────────────────────────────────────────────────┐
│ Q1. このタスクの結果を「クライアントに直接送る」    │
│     ／「対外公開する」？                          │
└────────────────────────────────────────────────┘
        │
        ├── YES ──→ ⚠️ 必ず人手で最終確認 + 該当者承認
        │
        └── NO ───→ Q2へ

┌────────────────────────────────────────────────┐
│ Q2. 法的・道義的リスクがある領域？                 │
│     （脆弱性・契約・個人情報）                     │
└────────────────────────────────────────────────┘
        │
        ├── YES ──→ ❌ AIに任せず人間が判断
        │           （必要なら顧問弁護士相談）
        │
        └── NO ───→ Q3へ

┌────────────────────────────────────────────────┐
│ Q3. ブランド整合・コピー感情・デザイン審美が       │
│     関わる？                                    │
└────────────────────────────────────────────────┘
        │
        ├── YES ──→ ⚠️ AIに任せて最終目視確認
        │
        └── NO ───→ ✅ AIに完全に任せる
```

---

## AI が止まったら、ためらわず人間にエスカレーション

AIが「これ以上判断できない」と返した場合、もしくは複数回試行しても結果が改善しない場合：

1. AI とのやり取りログをスクショまたはコピー
2. 案件CTO（櫻井理也）に Slack DM
3. 詳細は [`escalation.md`](./escalation.md)
