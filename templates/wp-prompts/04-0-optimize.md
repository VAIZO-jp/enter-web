## WP最適化を依頼

最終版HTML（`{{最終版HTMLファイル名}}`）を WordPress 固定ページ用に最適化してください。

## 最適化要件

1. `<head>` 内の `<meta>` / `<link>` / `<style>` を WP テーマと重複しないように整理
2. `<header>` / `<footer>` / `<nav>` はテーマに同等のものがあるため削除（テーマ側と統合）
3. **インラインCSSは body スコープ化**（例: `body.page-{{対象固定ページslug}} .xxx { ... }` で囲って既存テーマCSSと干渉しないように）
4. インラインJSはIIFEまたはモジュール化（テーマjQuery等との衝突を防止）
5. `canonical` / `og:url` / `twitter:url` / JSON-LD の `url` を `{{公開URL}}` に書き換え
6. 画像 `src` を WPメディアアップロード後のURL（`https://{{対象ドメイン}}/wp-content/uploads/YYYY/MM/`）に一括置換
7. CSP `<meta>` タグは WPサーバ設定と整合がなければ削除
8. GTM / GA タグは既存テーマで設定済みなら削除

- リポジトリ名: `{{案件略称}}-wp-demo`
