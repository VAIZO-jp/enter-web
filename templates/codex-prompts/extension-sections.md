## タスク: {{屋号}}公式サイトを「売上に繋がるLP」に拡張

## 役割

V/ENTER WEB事業部の実装ドラフト担当。既存の `index.html`（FV）を活かし、その下に売上に繋がる6セクションを追加して、1ページの完成版LPに仕立て直す。

## 起点ファイル

- `index.html`（既存。FV部分はデザインを維持）

## 出力

- 同じ `index.html` を上書き
- CSSは引き続き `<head>` 内に内包
- JS最小限のみ可（IntersectionObserver による静かなフェードイン）
- 外部画像URL不要、SVG / CSS で雰囲気を作る

## 構造（縦スクロールLP）

1. **HERO（既存FV）** ← そのまま維持。`body` の `overflow:hidden` は解除し縦スクロール可に
2. **CONCEPT** — 店の哲学
3. **SPACE** — 内装の佇まい
4. **{{業態固有セクション1}}** — 例: WHISKY & DRINKS（バー）/ MENU（飲食）/ EVENTS（ライブハウス）/ SERVICES（コーポレート）
5. **{{業態固有セクション2}}** — 例: A NIGHT AT {{屋号}}（時系列利用イメージ）/ STORY（コーポレート）
6. **RESERVATION / CONTACT** — 予約方法 or 問い合わせ
7. **ACCESS** — 行き方 + 略地図（CSSで描画）
8. **FOOTER** — 屋号・住所・電話・営業時間

各セクション間の縦ガターは `clamp(80px, 12vw, 160px)`。世界観統一。

## セクション仕様（業態別カスタマイズ）

業態に応じて 4-5 のセクション内容を入れ替える。下記は飲食・バー業態の例：

### 4. WHISKY & DRINKS（バー）

- リード文（17px / 行間1.9 / Noto Serif JP）
- シグネチャー3種（カードレイアウト、各カード黒地に細罫線・ゴールドアクセント）
- **価格目安**を表で明示（不安解消が目的）

| 項目 | 目安 |
|------|------|
| チャージ | お一人様 ¥{{2,000}} |
| 一杯あたり | ¥{{1,800}}〜¥{{4,500}} |
| 一夜あたり | ¥{{8,000}}〜¥{{15,000}} / 人 |
| お支払い | 現金・各種カード |

表の文字: 15px / 行間1.9

### 5. A NIGHT AT {{屋号}}（時系列）

縦タイムライン（左に時刻、右にコピー）：
- **{{19:00}}** — {{コピー1}}
- **{{19:05}}** — {{コピー2}}
- **{{20:30}}** — {{コピー3}}
- **{{22:00}}** — {{コピー4}}
- **{{02:00}}** — {{コピー5}}

各タイムスロットの左に細罫線・ゴールドの点

### 6. RESERVATION

- 受付時間 / キャンセル / ドレスコード を左カラム
- 大きく電話番号 + tel: リンクボタン を右カラム

### 7. ACCESS

- 住所 / 最寄駅 / 目印 を左カラム
- CSSで描いた略地図（道・駅マーカー・店マーカーの抽象表現）を右カラム

## 追従要素（全画面共通・業態問わず）

- **右下に電話予約フローティングボタン**（`tel:{{0300000000}}`、半透明黒・ゴールド枠・スクロール時のみ表示）
- 既存FV時は非表示、CONCEPTセクション以降から表示
- 飲食・店舗案件は **LINE CTAも併記**（タイプ:`https://lin.ee/xxxxx`）

## デザイン規定（再掲）

- 配色: 既存維持（黒 / オフホワイト / 控えめゴールド）
- 書体: Noto Serif JP（本文）/ Cormorant Garamond / Playfair Display（英字見出し）
- **本文 17px / テーブル 15px / 行間 1.9** 厳守
- セリフ系・大きな余白・薄い罫線・微細グレイン継続
- ホバーは控えめ（線が引かれる程度）

## 守ってほしいこと

- 既存FVのデザインは破壊しない
- 軍事比喩・否定列挙・採用語禁止
- 「〜していただきます」より「します」を優先（過剰丁寧は避ける）
- TODOで埋めず、その場で完成
- 価格・住所・時間は仕様書記載のまま使用（プレースホルダ表記OK）
- アクセシビリティ: コントラストAA以上、見出し階層、`aria` 属性、`prefers-reduced-motion` 対応
