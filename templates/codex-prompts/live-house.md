## デザイン要件

- **トーン**: HERITAGE_DARK / URBAN_MUSIC 系統（クラシックロックや渋いジャズに似合う）
- **配色**: 主色 `#0a0a0a` ベース、アクセントに業態に合わせた色（{{ネオン管風 / アンバー / 燻んだレッド}}）
- **書体**: タイポグラフィ重め。Inter 900 + Noto Sans JP 700。歌詞・引用には Noto Serif JP も可
- **レイアウト**:
  - ヒーロー: 大きなキャッチ + 直近ライブのカウントダウン or バナー
  - イベントカード（時系列）: 日付 / 出演 / チケット情報 / 詳細リンク
  - About / Access / ブッキング問い合わせ
  - 必須: 電話 + LINE のCTAを追従バーで常設
- **JSON-LD `Event`**: 直近のライブ情報を構造化データ化（GSC リッチ結果用）

## イベントセクション仕様

```
{{
  "events": [
    {
      "date": "2026-05-15",
      "title": "{{ライブタイトル}}",
      "artists": ["{{出演者1}}", "{{出演者2}}"],
      "open": "18:00",
      "start": "19:00",
      "advance_price": 3500,
      "door_price": 4000,
      "ticket_url": "{{チケット販売URL}}"
    }
  ]
}}
```

イベントカードは縦タイムライン形式。過去のイベントは別アコーディオンで隠す。

## 守ってほしいこと

- 仕様外の機能（チャット・予約フォーム等）は勝手に追加しない
- 軍事比喩・否定列挙・採用語は使わない
- 「敷居が高い」「真の音楽好き」等の選別的表現は避け、開かれたトーンに
- 飲食・店舗案件のため、**電話 + LINE のCTAを全ページで追従バー常設**
- メールは `info@vaizo.jp` を使用、`.co.jp` 不使用
- 文字サイズ: 本文17px、テーブル15px、行間1.9厳守
- アクセシビリティ: コントラスト比AA以上、フォーカスリング、`prefers-reduced-motion` 対応

## ⚠️ 過去のリグレッション事故（必読）

仙台レトロ案件で `mailto:` の cc 形式修正により全メーラー起動不能のリグレッション事故が発生（修正ID `F-RBP-202605-001/025/026`）。詳細: [`troubleshooting/mailto-regression.md`](../../troubleshooting/mailto-regression.md)

**今回のプロンプトでは**:
- `mailto:` リンクの形式は `mailto:address?subject=...&body=...` 形式（カンマ区切りcc不可）
- 複数宛先が必要な場合は `mailto:to1@example.com?cc=cc1@example.com,cc2@example.com` 形式
- 必ず実機（Outlook / Gmail / Apple Mail）で起動テストする
