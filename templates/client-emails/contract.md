# メール雛形：契約書送付

> 採用案決定後、業務委託契約書を送付する際のメール。

---

## 件名

```
【契約書】{{屋号 / 企業名}}様 {{案件名}} 業務委託契約書をお送りします
```

## 本文（雛形）

```
{{担当者ご芳名}} 様

お世話になっております。
株式会社VAIZO V/ENTER WEB事業部の {{差出人氏名}} です。

このたびは、デザイン案 {{採用案 例: 案B HERITAGE_DARK}} のご採用ありがとうございます。
業務委託契約書をお送りいたしますので、ご確認のほどお願いいたします。

──────────────
■ 添付書類
──────────────

1. 業務委託契約書（{{2部}} / 製本済）
2. 業務範囲明細書
3. 着手金請求書（契約締結後の発行用ドラフト）

──────────────
■ ご確認・ご捺印のお願い
──────────────

契約書 2部のうち1部にご捺印（社印 + 代表者印）の上、
{{返送方法 例: レターパックライト同封}} にてご返送をお願いいたします。

ご返送先:
〒980-0021
```

## 守るルール

- 契約書本体は **顧問弁護士レビュー済の最新版** を使用
- 業務範囲明細書は提案書・見積書と一致
- 業務委託パートナーへの再委託条項を必ず確認

## チェックリスト

- [ ] 契約書本体が最新版（顧問弁護士承認済）
- [ ] 業務範囲明細書 = 見積書 = 提案書 で内容一致
- [ ] 公開希望日・瑕疵担保期間・支払条件が見積書と一致
- [ ] 印紙が正しく貼付されているか（業務委託契約は通常 不課税）
- [ ] 製本（2部、各部に印紙）
- [ ] レターパック・配達証明等で記録に残る送付方法
