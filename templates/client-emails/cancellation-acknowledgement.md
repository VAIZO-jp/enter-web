# メール雛形：解約受領確認

> 月次運用契約の解約申し出を受領した際の確認メール。

---

## 件名

```
【解約受領】{{屋号 / 企業名}}様 月次運用契約解約のご連絡を承りました
```

## 本文（雛形）

```
{{担当者ご芳名}} 様

お世話になっております。
株式会社VAIZO V/ENTER WEB事業部の {{差出人氏名}} です。

このたびは月次運用契約解約のご連絡をいただき、ありがとうございました。
内容を確認いたしましたので、ご報告いたします。

──────────────
■ 解約条件の確認
──────────────

契約書に基づき:
- 解約申出日: {{YYYY-MM-DD}}
- 契約終了日: {{解約申出日 + 1ヶ月後}}
- 最終請求月: {{YYYY-MM}}（解約月分）

──────────────
■ 引き渡し計画
──────────────

契約終了日（{{YYYY-MM-DD}}）までに、以下を引き渡しいたします:
1. すべての権限・アカウント情報の整理
2. 制作中・運用中のコンテンツの最終版
3. アクセス解析・SEOレポートの最終版

ご質問・ご要望があれば、契約終了日までの間お気軽にご連絡ください。

──────────────
■ 今後について
──────────────

引き続き、{{屋号}}様の発展を心よりお祈りしております。
将来的に再度のご相談やお力添えが必要な際は、いつでもお声がけください。

──────────────
株式会社VAIZO V/ENTER WEB事業部
{{差出人氏名}}（{{役割}}）
info@vaizo.jp
──────────────
```
