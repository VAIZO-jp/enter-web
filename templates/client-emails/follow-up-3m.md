# メール雛形：公開3ヶ月後フォローアップ

> 公開から3ヶ月経過時のフォローアップメール。次案件・口コミ獲得の布石。

---

## 件名

```
【3ヶ月経過】{{屋号 / 企業名}}様 サイト公開から3ヶ月、その後いかがでしょうか
```

## 本文（雛形）

```
{{担当者ご芳名}} 様

お世話になっております。
株式会社VAIZO V/ENTER WEB事業部の {{差出人氏名}} です。

{{案件名}} の公開から3ヶ月が経過しました。
その後の運用状況はいかがでしょうか。

──────────────
■ 3ヶ月後のチェックポイント
──────────────

良ければ以下をご確認ください:
1. 公開後の問い合わせ・予約数の変化
2. アクセス推移（Google Analytics 4）
3. 検索順位・インプレッション（Google Search Console）
4. 操作で困っている点・更新が滞っている箇所

──────────────
■ ご提案
──────────────

3ヶ月運用したうえで、以下のいずれかをご検討いただけます:

A. ご相談MTG（30分・無料）
   現状の運用状況を一緒に振り返り、改善ポイントをご提案します。

B. 月次運用契約への移行
   コンテンツ更新・SEO・パフォーマンス監視を VAIZO で代行いたします。
   月額3万円〜ご相談承っております。

C. 追加コンテンツ・改修
   ブログ機能追加、新ページ追加、デザイン改修など、別案件としてご対応します。

──────────────
■ ご返信不要です
──────────────

ご返信いただかなくても問題ありません。ご検討の余地があれば、いつでもお声がけください。

──────────────
株式会社VAIZO V/ENTER WEB事業部
{{差出人氏名}}（{{役割}}）
info@vaizo.jp
──────────────
```
