# メール雛形：キックオフMTG案内

> 契約締結 + 着手金入金確認後、最初のキックオフMTGを設定する際のメール。

---

## 件名

```
【キックオフ】{{屋号 / 企業名}}様 {{案件名}} 制作キックオフMTGのご案内
```

## 本文（雛形）

```
{{担当者ご芳名}} 様

お世話になっております。
株式会社VAIZO V/ENTER WEB事業部の {{差出人氏名}} です。

このたびは契約書のご返送・着手金のお振込ありがとうございました。
本制作着手にあたり、キックオフMTGを設定いたします。

──────────────
■ MTG日程候補
──────────────

下記の3候補からお選びください:
1. {{YYYY-MM-DD HH:MM}}
2. {{YYYY-MM-DD HH:MM}}
3. {{YYYY-MM-DD HH:MM}}

所要時間: 60分
形式: オンライン（Google Meet）/ 訪問（{{都道府県}}）/ 電話

──────────────
■ アジェンダ
──────────────

1. 案件目的・KPIの再確認
2. スケジュール（公開予定日: {{YYYY-MM-DD}}）
3. 体制（VAIZO側担当・クライアント側担当）
4. 必要な情報・素材の受領計画
5. 決定権者の確認
6. 質疑応答

──────────────
■ MTG前にご準備いただきたい資料
──────────────

下記をご用意いただけると、効率的に進行できます:

- 既存サイトの管理画面ログイン情報（WordPress / サーバー）
- 既存ロゴデータ（AI / SVG / 高解像度PNG）
- 過去の制作物（メニュー / パンフレット / 名刺等）
- 競合・参考にしたいサイトのURL（あれば）
- 公開時に掲載したい写真・文章（着手後でも可）

詳細リストは MTG前にあらためてお送りします。

──────────────
■ セキュアな共有方法（重要）
──────────────

ログイン情報・APIキー等の機密情報は、メール本文や Slack 等への
直接記載は避け、必ず下記の方法でお送りください。

【方法 A】1Password 共有リンク（推奨）
  キックオフMTG後、VAIZO側から 1Password の入力フォーム（時限式リンク）を
  お送りします。そのリンクに直接ご入力いただくことで、暗号化された状態で
  VAIZO に共有されます。

  - 1Password アカウント不要（リンクから直接入力）
  - リンクには有効期限（72時間）を設定
  - 受信確認後、VAIZO 側で安全な金庫（1Password Vault）に保管

【方法 B】口頭でのご共有（中レベル難度の場合）
  上記が難しい場合は、お電話にて口頭でお伝えください。
  VAIZO 側でその場で 1Password に登録いたします。

【絶対に避けたい方法】
  - メール本文への平文記載
  - Slack や チャット への直接投稿
  - Excel・Word ファイルでの添付（特にパスワード保護なし）

万一、上記NG方法でお送りいただいた場合、VAIZO側で受領後即時に
1Password へ移管し、元のメッセージ・ファイルは安全に削除いたします。
セキュリティ強化のため、次回からは方法A をご利用いただけますと幸いです。

──────────────
■ 連絡方法
──────────────

MTG日程ご回答 + ご質問は本メールへの返信、または下記の連絡先まで:

電話: {{担当連絡先}}
Slack: {{連絡用チャンネル / DM 案内}}（本案件専用Slack Connect招待 別送）

──────────────
■ 制作スケジュール（仮）
──────────────

- {{YYYY-MM-DD}}: キックオフMTG
- {{YYYY-MM-DD}}: 素材受領完了
- {{YYYY-MM-DD}}: デモ確認
- {{YYYY-MM-DD}}: 公開作業
- {{YYYY-MM-DD}}: 公開後フォロー開始

──────────────
■ ご返信お待ちしております
──────────────

ご都合の良いMTG日程を、メールでお知らせください。

──────────────
株式会社VAIZO V/ENTER WEB事業部
{{差出人氏名}}（{{役割}}）
info@vaizo.jp
──────────────
```
