# メール雛形：引き渡し完了報告（オフボーディング）

> 案件終了時、クライアントへ引き渡し完了を報告する際のメール。

---

## 件名

```
【引き渡し完了】{{屋号 / 企業名}}様 {{案件名}} のお引き渡しが完了いたしました
```

## 本文（雛形）

```
{{担当者ご芳名}} 様

お世話になっております。
株式会社VAIZO V/ENTER WEB事業部の {{差出人氏名}} です。

{{案件名}} の制作・公開・運用が完了いたしましたので、引き渡しのご報告をいたします。

──────────────
■ 引き渡し物
──────────────

1. WordPress 管理画面ログイン情報（既送付）
2. サーバー管理画面ログイン情報（既送付）
3. ドメイン管理画面の権限（移譲済 / 別途確認）
4. Google Analytics 4 / Search Console / Tag Manager の権限（移譲済）
5. 公開サイトコード一式（GitHub Repo URL or ZIP）
6. 画像素材一式（圧縮前 / 後）
7. 制作資料（議事録・修正対応表・公開後30日レポート）

──────────────
■ 受領確認のお願い
──────────────

上記の引き渡し物について「受領しました」のご返信をお願いいたします。

──────────────
■ 今後について
──────────────

引き渡し完了後は、{{案件名}} の通常運用に関する VAIZO 側のサポートは終了いたします。

公開後の不具合対応は、契約書記載の瑕疵担保期間内で対応いたします。
追加の改修・運用代行をご希望の場合は、別途ご相談ください。

──────────────
株式会社VAIZO V/ENTER WEB事業部
{{差出人氏名}}（{{役割}}）
info@vaizo.jp
──────────────
```
