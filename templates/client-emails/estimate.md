# メール雛形：見積書送付

> 商談前 or 商談後の概算見積書送付。提案書一式と一緒に送る場合は [`proposal.md`](./proposal.md) を使用。

---

## 件名

```
【お見積】{{屋号 / 企業名}}様 {{案件名 例: Webサイトリニューアル}} お見積書をお送りします
```

## 本文（雛形）

```
{{担当者ご芳名}} 様

お世話になっております。
株式会社VAIZO V/ENTER WEB事業部の {{差出人氏名}} です。

ご依頼いただいた {{案件名}} につきまして、お見積書を作成いたしました。
添付ファイルをご確認ください。

──────────────
■ 見積概要
──────────────

案件名: {{案件名}}
基本料金: {{金額}} 円（税込）
オプション: {{有無、ある場合内訳}}
合計: {{合計金額}} 円（税込）

支払条件: {{着手金30% / 中間金30% / 残金40% など}}
有効期限: {{発行日 + 30日}}

──────────────
■ 見積範囲
──────────────

- {{含まれる作業1: トップページ + N子ページの制作}}
- {{含まれる作業2: 写真選定（最大Nカット）・文章調整}}
- {{含まれる作業3: WordPress固定ページ統合}}
- {{含まれる作業4: 公開後30日のサポート}}
- {{含まれる作業5: 脆弱性チェック・基本的なSEO対策}}

──────────────
■ 見積範囲外
──────────────

- 撮影手配（オプション +{{金額}}円）
- ロゴ刷新（オプション +{{金額}}円）
- 月次運用契約（別途お見積）

──────────────
■ 次のステップ
──────────────

見積内容にご了承いただける場合、下記のいずれかでご返信ください:
1. 「契約締結に進みたい」→ 契約書ドラフトをお送りします
2. 「内容を調整したい」→ 調整希望項目をご教示ください
3. 「他社見積と比較中」→ 比較期限のご連絡をいただけますと幸いです

ご不明点・調整希望は、メールもしくはお電話でお気軽にどうぞ。

──────────────
株式会社VAIZO V/ENTER WEB事業部
{{差出人氏名}}（{{役割}}）
info@vaizo.jp
──────────────
```

## 添付

- 見積書PDF（Drive `006_経理部.../01_帳票テンプレート/見積書テンプレート/` を使用）
- 必要なら制作範囲の詳細PDF

## チェックリスト

- [ ] 見積書の発行日・有効期限・案件番号が記載されている
- [ ] 振込先・適格請求書発行事業者番号が正しい
- [ ] 税込・税別が明確
- [ ] 含まれる作業・含まれない作業が明確
- [ ] 支払条件が明記されている
- [ ] 文体: 過剰丁寧を避け、具体的な内容に集中
