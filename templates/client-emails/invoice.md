# メール雛形：請求書送付

> 着手金 / 中間金 / 残金の各タイミングで使用するメール雛形。

---

## 共通件名

```
【ご請求】{{屋号 / 企業名}}様 {{案件名}} {{第N回}}請求書をお送りします（請求番号: {{番号}}）
```

## 添付

## チェックリスト

- [ ] 請求番号が連番になっている
- [ ] 振込先（VAIZO法人口座）が正しい
- [ ] 支払期限（標準: 翌月末 or 14日後）
- [ ] 適格請求書発行事業者番号が記載
- [ ] 税込・税別が明確
- [ ] 案件番号・契約書番号と整合

## 督促（支払期限超過時）

詳細: [`handbook/08-finance-billing.md`](../../handbook/08-finance-billing.md) §8 督促フロー

- 1営業日超過: 経理部からメール
- 5営業日超過: 案件CTO から電話
- 10営業日超過: 橋本CEO 主導、書面催告書
