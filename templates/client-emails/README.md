# クライアント宛メール雛形集

| ファイル | 用途 |
|---------|------|
| [`vulnerability-report-cover.md`](./vulnerability-report-cover.md) | 脆弱性レポート + デモトップを送付するカバーレター |

すべてのメールで遵守:
- メールアドレス: `info@vaizo.jp`（`.co.jp` 不使用）
- V/ブランド表記は半角スラッシュ「/」のみ
- 軍事比喩・否定列挙・採用語・階層用語は使わない
- 飲食/店舗案件は CTA に電話 + LINE を併記
