判断フロー：契約形態の選択（買切り / 月次運用 / ハイブリッド）

案件単位の契約形態を決める判断ツリー。クライアントの予算・運用体制・成果志向に応じて選定する。

3つの契約形態

形態 報酬構造 期間 適用
買切り（Web制作のみ） 一括（または分割払い） 制作期間 + 公開後30日 LP単発・予算制約
月次運用契約 月額固定 6ヶ月以上推奨 継続的な改修・SEO・運用
ハイブリッド 制作費 + 月額運用費 制作後 + 月次運用 標準パターン（推奨）

各形態の詳細

A. 買切り（Web制作のみ）

適用パターン

  • LP単発（イベント告知 / キャンペーン / 期間限定）
  • 予算制約が厳しい
  • クライアントが自走できる体制
  • VAIZO 側のリソース集中（運用受けると拘束される）

報酬構造

  • 着手金30% / 中間金30% / 残金40%
  • または 一括前払い（小規模案件）

公開後サポート

  • 30日間: 軽微な修正・調整は無償
  • 31日〜90日: 軽微な修正は応相談（時間単価 5,000円〜）
  • 91日〜: すべて追加見積

注意点

  • 契約終了後の運用責任はクライアント側
  • WPアップデート・プラグイン互換性問題はクライアント対応
  • ドメイン・サーバーの権限移譲を確実に行う

B. 月次運用契約

適用パターン

  • 既存サイトのリニューアル後、継続運用
  • SEO中心の運用案件
  • ブログ・ニュース更新を VAIZO が代行
  • 多店舗展開・新店オープン対応

報酬構造

  • 月額固定（標準: 3万円〜10万円）
  • 内訳例（月額5万円の場合）:
    • SEO 改善: 月3時間
    • コンテンツ更新: 月5記事
    • パフォーマンス監視: 自動 + 月次レポート
    • 軽微な改修: 月3時間まで無償
  • 大規模改修は別見積

契約期間

  • 最低 6ヶ月
  • 自動更新（解約は1ヶ月前申告）

KPI

  • セッション数の月次推移
  • GSC インプレッション・クリック推移
  • Lighthouse スコア維持
  • 月次レポート提出

注意点

  • 「月次運用契約だけ」は失敗しやすい（制作の文脈を共有していない別業者だと品質が落ちる）
  • VAIZO が制作した案件の運用継続が理想

C. ハイブリッド（推奨パターン）

適用パターン

  • 標準的な案件（VAIZO 推奨）
  • リニューアル制作 + 公開後の継続運用

報酬構造

  • 制作費: 一括（または着手金30% / 中間金30% / 残金40%）
  • 月次運用費: 公開後の月額固定

契約期間

  • 制作: 完了まで
  • 運用: 公開後6ヶ月最低、自動更新

メリット

  • VAIZO 側: 安定収益
  • クライアント側: 制作の文脈を理解した業者に運用を任せられる

提案時の伝え方

1次商談での選択肢提示

「ご予算と運用体制に応じて、3つの形態をご提案しています：

A. 買切り（Web制作のみ）
   - 〜50万円程度
   - 公開後30日のサポート付き
   - その後は基本的にクライアント様で運用

B. ハイブリッド（推奨）
   - 制作費 + 月次運用契約
   - 制作費はAと同等
   - 月次運用は月額3万円〜
   - VAIZO がコンテンツ更新・SEO・改修を継続

C. 月次運用のみ（既存サイト運用）
   - 既存サイトをVAIZOが運用
   - 月額3万円〜10万円

御社の状況に応じて、最適な形態をご相談しましょう。」
