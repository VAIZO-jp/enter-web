HTML → PDF 化（Codex 内 or ローカル）

Codex で HTML が完成したら、以下のいずれかで PDF 化。

方法 A: Codex に PDF 変換スクリプトも書かせる

「上記 report.html を Playwright で A4 PDF に変換する
 Node.js スクリプト convert.mjs を書いてください。
 出力は report.pdf。
 print background: true、margin 18/16mm。」

方法 B: 既存の build.mjs パターンを使う

node -e "
const { chromium } = require('playwright');
(async () => {
  const browser = await chromium.launch();
  const page = await (await browser.newContext()).newPage();
  await page.goto('file://' + require('path').resolve('report.html'));
  await page.waitForTimeout(1000);
  await page.pdf({
    path: 'report.pdf',
    format: 'A4',
    margin: {top:'18mm', bottom:'18mm', left:'16mm', right:'16mm'},
    printBackground: true
  });
  await browser.close();
})();
"

 1. 恐怖訴求（危険です / 至急対応必要 等）が無いか
 2. 直結セールス（うちで対応 等）が無いか
 3. 公開情報の範囲を超える推測が無いか
 4. すべて事実ベースで淡々としたトーンか」

非エンジニア向け解説の検証：

「各項目の解消手順を、IT初心者の店舗オーナーが読んで
 自分で対応 or 業者に依頼判断ができるレベルに書き直してください。
 専門用語は括弧書きで補足。」

ありがちな失敗と対処

  • Codex が実際にURLにアクセスできず推測で書く → ブラウザツールが有効か確認、または Claude Code + web-cloner MCP に切り替え
  • 恐怖訴求トーンになる → 「公開情報の範囲で〜」のトーンを再明示
  • PDF化で改ページが汚い → CSS に page-break-inside: avoid をテーブル/グラフに追加
  • HTML → PDF で日本語フォントが崩れる → Playwright の networkidle 待機、または webfont を base64 埋め込み
