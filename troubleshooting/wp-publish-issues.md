# WP公開作業のトラブルシューティング

> [`handbook/04-wp-publish-guide.md`](../handbook/04-wp-publish-guide.md) で詰まったときの対処集。

---

## 症状別の対処

### 1. ログインできない

| 原因 | 対処 |
|------|------|
| ID/パスワード間違い | 再確認、何度も間違えるとIPロック |
| IPロック（数回失敗で発動） | AIに「Xserver IP ロック解除方法」と聞く、もしくはロック解除依頼をサーバー業者に |
| ログインURLの変更（セキュリティプラグイン） | クライアントに正規URLを再確認 |

### 2. 画像のアップロードでエラー

| 原因 | 対処 |
|------|------|
| 1ファイル容量制限（通常 1GB） | サイズダウン、解像度を下げて再試行 |
| サーバー側の容量制限（`upload_max_filesize`） | サーバー業者に相談、もしくは画像を WebP 化 |
| 同名ファイル衝突 | 古いものを先に削除してから再アップ |
| ネットワーク不安定 | 10〜15枚ずつ分割して再試行 |

### 3. ページが真っ白／500エラー

**最優先**: 即時復元する。原因調査は後。

```
Step 1: All-in-One WP Migration の「インポート」を開く
Step 2: ステップ2-1で取得した .wpress ファイルをドラッグ＆ドロップ
Step 3: 復元完了を待つ（数分）
Step 4: 公開URLを別タブで開いて表示確認
Step 5: クライアントに「一時的に乱れたが復旧した」旨を即報告
Step 6: 落ち着いてから原因調査
```

### 4. 崩れ・表示異常

| 症状 | 第一手 |
|------|-------|
| ヘッダー二重表示 | 統合方式B → 方式Aに切り替え検討 ([`decision-trees/wp-integration-method.md`](../decision-trees/wp-integration-method.md)) |
| CSS が効かない | テーマの優先度に負けている → `body.page-{slug}` でスコープ化 |
| JS が動かない | jQuery 衝突 → IIFE で囲う or テーマ jQuery を回避 |
| 画像が出ない | パス間違い、ステップ3-1の画像アップロードを再確認 |
| フォントが違う | Google Fonts の読み込みがブロックされている可能性、CSP確認 |

### 5. プラグイン干渉

| プラグイン | 干渉ポイント |
|----------|------------|
| Yoast SEO | meta タグを上書きする → 固定ページ単位で Yoast meta を再設定 |
| Elementor 等 Page Builder | ページ全体を Elementor が制御 → カスタムHTMLウィジェットを使うかテンプレート分離 |
| 画像最適化系（Smush、EWWW） | 画像を勝手に変換 → 個別ファイル除外設定 |
| キャッシュ系（WP Rocket、W3 Total Cache） | 古いCSS/JSがキャッシュされる → 該当ページのキャッシュ除外 |

### 6. スマホ表示で横スクロール発生

| 原因 | 対処 |
|------|------|
| 画像・iframe が `max-width: 100%` 未設定 | CSSに `img, iframe { max-width: 100%; height: auto; }` 追加 |
| テーブルがコンテナ幅を超える | `overflow-x: auto` でラップ |
| 絶対値（px）で固定された要素 | レスポンシブ単位（vw、%、`clamp()`）に置換 |

### 7. Lighthouse パフォーマンスが低い

| スコア帯 | 主な原因 |
|---------|--------|
| 50 未満 | 画像未圧縮、外部スクリプト多数 |
| 50-70 | LCP 遅延（ファーストビューが重い） |
| 70-90 | CLS（レイアウトシフト）、未使用CSS |
| 90+ | 維持OK |

対処:
- 画像を WebP 化、`loading="lazy"`、`width`/`height` 明示
- フォントは `font-display: swap`、必要最小限のウェイトのみ
- 不要な外部スクリプト削除（GTM、ヒートマップ等を最低限に）
- Critical CSS をインライン化、それ以外は遅延読み込み

## 復元手順（バックアップから戻す）

### A. 完全復元（致命的不具合）

```
1. WP管理画面の「All-in-One WP Migration」→「インポート」
2. ステップ2-1で保存した .wpress ファイルをドラッグ＆ドロップ
3. 復元完了まで待つ（数分〜数十分）
4. ログイン情報がリセットされる場合があるので注意
5. 公開URLを別タブで開いて表示確認
```

### B. ページ単体の復元（軽微な崩れ）

```
1. 該当固定ページの編集画面を開く
2. 編集欄を Ctrl+A → Delete でクリア
3. ステップ2-3 で保存した本文テキストファイルを開く
4. Ctrl+A → Ctrl+C でコピー
5. WP編集欄に Ctrl+V で貼り付け
6. 「更新」をクリック
```

### C. リビジョンから戻す（直近の編集を取り消し）

```
1. 該当固定ページの編集画面を開く
2. 右側「リビジョン」をクリック
3. ステップ2-3 で控えたリビジョン番号より前のリビジョンを選択
4. 「このリビジョンを復元」をクリック
```
