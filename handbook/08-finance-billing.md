# 08 — 経理・請求フロー

> 案件単位の経理・請求・入金管理の標準フロー。

---

## 1. 全体フロー

```
キックオフ → 見積発行 → 契約締結 → 着手金請求（30%）→ 制作 → 公開
   → 中間金請求（30%）→ 公開後30日 → 残金請求（40%）→ 入金確認 → 案件クローズ
```

請求3分割は標準。案件規模・契約条件に応じて 1回（公開後一括）または 2回（半金 + 半金）も可。

## 2. 担当・権限

| 役割 | 担当 |
|------|------|
| 見積作成 | 案件CTO（櫻井理也） |
| 契約書作成・送付 | 橋本CEO + 顧問弁護士テンプレ |
| 請求書発行 | 経理部 + 案件CTO |
| 入金確認 | 経理部 |
| 督促 | 経理部 → 橋本CEO エスカレーション |

## 3. 単価ガイドライン

業態ランク別の標準単価：

| ランク | 単価帯 | 例 |
|-------|------|------|
| S | 80万〜200万 | 銀座系高級バー、隠れ家業態 |
| A | 30万〜80万 | 飲食、ライブハウス、地方の老舗 |
| B | 10万〜30万 | ホームページ業者制作の店舗サイト、リニューアル放置型 |

オプション:
- ロゴ刷新: +10万〜30万
- 撮影手配: +5万〜20万
- 文章執筆代行: +5万〜15万
- 月次運用契約: 月額3万〜10万（[`decision-trees/contract-type.md`](../decision-trees/contract-type.md) 参照）

## 4. 見積発行

### 見積テンプレート

Drive `006_経理部_事務系・経費精算等/01_帳票テンプレート/` にあるVAIZO公式見積書テンプレを使用。
フォルダID: `1Bv8-l2_Z6CldW8w716AU0EZ4I5wUdOI9`

### 必須項目

- 件名（例: `{{屋号}}様 Webサイトリニューアル ご提案資料一式`）
- 見積日 / 有効期限（標準30日）
- 案件番号（[`runbooks/new-client-kickoff.md`](../runbooks/new-client-kickoff.md) §1 参照）
- 内訳（基本料金 / オプション / 月次運用 等）
- 小計 / 消費税 / 合計
- 支払条件（着手金30% / 中間金30% / 残金40%、または1回払い）
- 振込先

### メール送付

雛形: [`templates/client-emails/estimate.md`](../templates/client-emails/estimate.md)

## 5. 契約書

### 標準契約書

Drive `006_経理部_事務系・経費精算等/02_契約書テンプレート/` の VAIZO 標準業務委託契約書を使用。
顧問弁護士レビュー済（Phase 0 完了後の最新版）。

### 必須条項

- 業務範囲
- 納期
- 検収条件
- 報酬・支払条件
- 瑕疵担保期間（標準: 公開後14日間、契約により延長可）
- 知的財産権の帰属
- 秘密保持
- 解除条件
- 損害賠償の上限

### 業務委託パートナー（OneBe等）との契約

- 単価表添付（指揮命令性なしを明記）
- 偽装請負回避: タスク単価ベース、稼働時間管理しない
- 詳細: メモリ `project_onebe_partnership.md`

### メール送付

雛形: [`templates/client-emails/contract.md`](../templates/client-emails/contract.md)

## 6. 請求書発行

### タイミング

| 段階 | 発行日 | 金額 |
|------|-------|------|
| 着手金 | 契約書捺印日 | 見積総額 × 30% |
| 中間金 | 制作着手から2週間後 | 見積総額 × 30% |
| 残金 | 公開後30日 | 見積総額 × 40% |

### 請求書テンプレート

Drive `01_帳票テンプレート/` の請求書テンプレを使用。

### 必須項目

- 案件番号
- 請求日 / 支払期限（標準: 翌月末）
- 振込先（VAIZO 法人口座）
- 内訳・金額
- 適格請求書発行事業者番号（インボイス番号、Phase 0完了後に明記）

### メール送付

雛形: [`templates/client-emails/invoice.md`](../templates/client-emails/invoice.md)

## 7. 入金確認

- 経理部が VAIZO 法人口座を週次で確認
- 入金確認後、Slack `#経理部_経費精算-仕訳`（C0AVBV8AJ4W）で報告
- 案件CTO に連絡 → クライアントに領収書送付（必要時）
- Drive 案件フォルダ `00_経理/入金記録/` に記録

## 8. 督促フロー

### 支払期限超過

| 経過日数 | 対応 |
|---------|------|
| +1営業日 | 経理部 → クライアント担当者にメール（テンプレ: `templates/client-emails/reminder-1.md`、Phase 2 で追加予定） |
| +5営業日 | 経理部 → 案件CTO に連絡、CTO が電話 |
| +10営業日 | 橋本CEO 主導、書面催告書（顧問弁護士監修） |
| +30営業日 | 法的措置検討 |

## 9. 業務委託パートナー（OneBe等）への支払い

- 案件完了後、OneBe からの請求書受領
- VAIZE 経理部が確認 → 翌月末払い
- 支払通知書を Drive `006_経理部.../03_業務委託費/` に保管
- 詳細: メモリ `project_vaizo_web_ops.md` § C1（業務委託費は ⑤業務委託費でタスク単価ベース管理）

## 10. インボイス制度対応

- VAIZO は適格請求書発行事業者（番号は Phase 0 完了後に公開）
- 業務委託パートナーから受領する請求書は適格請求書要件を満たすか確認
- 不備があれば修正依頼

## 11. 月次経理締め

- 毎月5日: 前月分の売上・経費を仕訳確定
- 毎月10日: 予実管理レポート（社内共有）
- 詳細: メモリ `project_vaizo_web_ops.md` § C4（月次集約xlsx 経由のみ）
