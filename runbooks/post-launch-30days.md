# Runbook：公開後30日のフォロー

> 公開して終わりではなく、30日間で「公開時に取り切れなかったSEO・解析・改修」を完了させる。

---

## Day 0（公開当日）

- [`runbooks/deploy-day.md`](./deploy-day.md) を完了

---

## Day 1（公開翌日）

### 朝のチェック

- [ ] 公開URLを開いて、夜間にトラブルが起きていないか確認
- [ ] GA4 / GSC でアクセスが計測されているか確認
- [ ] 問い合わせフォームに前日のテストメール以外の反応がないか確認

### Google Search Console 設定

- [ ] サイトマップ送信（`https://{{ドメイン}}/sitemap.xml`）
- [ ] URL検査で公開URLのインデックス状況確認
- [ ] 必要なら「インデックス登録をリクエスト」

---

## Week 1（公開後1週間）

### Lighthouse 再計測

- [ ] PC / モバイル両方で Lighthouse 計測
- [ ] パフォーマンス・SEO・アクセシビリティ・ベストプラクティス スコアを記録
- [ ] 公開当日のスコアと比較
- [ ] 70 未満の項目があれば改修計画

### コンソールエラー確認

- [ ] Chrome DevTools で公開URL を開き、コンソールエラーがないか
- [ ] エラーがあれば原因調査・修正

### Search Console モバイルユーザビリティ

- [ ] モバイルユーザビリティの問題がないか確認
- [ ] あれば修正（タップ要素のサイズ、コンテンツ幅等）

### 軽微な調整

- [ ] クライアントから受けた「公開後のお気づきの点」を反映
- [ ] 修正は契約上の「公開後XX日以内の瑕疵担保」範囲か確認

---

## Week 2（公開後2週間）

### GA4 / GSC アクセス推移確認

- [ ] 公開後2週間のセッション数・PV・直帰率を記録
- [ ] 想定との差異を確認
- [ ] 流入チャネル（Organic / Direct / Referral / Social）の構成確認

### 競合サイトとの比較（任意）

- [ ] パッシブスキャンツールで競合上位サイトを確認
- [ ] パフォーマンス・SEOで明らかに劣る項目があれば改修候補

---

## Week 3-4（公開後3-4週間）

### コンテンツ追加の検討

- [ ] クライアントから「ブログ記事」「お知らせ」等の追加コンテンツ要望ヒアリング
- [ ] 必要なら追加見積

### MEO（Googleビジネスプロフィール）連携

- [ ] Google Maps での店舗情報が正しいか確認
- [ ] サイトURL がプロフィールに登録されているか確認
- [ ] 写真・営業時間の更新

### SNS 連携（必要なら）

- [ ] Instagram / X / Facebook 等とのリンク確認
- [ ] OGP画像が正しく表示されるか確認（Twitter Card / Facebook Debugger）

---

## Day 30（公開後30日）

### 振り返りMTG（クライアントと）

- [ ] 30分のMTG設定
- [ ] アジェンダ:
  - 30日間のアクセス推移
  - 問い合わせ・予約等のCV件数
  - クライアント側で気づいた点
  - 改修・追加コンテンツの希望
  - 次のフェーズ（運用継続契約・追加プロジェクト）

### 30日後レポート

- [ ] Drive 案件フォルダ `公開作業/30日後レポート_{{YYYYMMDD}}.md` を作成
- [ ] 内容:
  - 公開日・経過日数
  - GA4 アクセス推移グラフ
  - GSC インプレッション・クリック数推移
  - Lighthouse スコア（公開時 → 30日後）
  - 問い合わせ・予約等のCV件数
  - クライアントからの主要フィードバック
  - 今後の改修・運用方針

### 内部振り返り

- [ ] [`troubleshooting/`](../troubleshooting/) への追記が必要な学びがあるかレビュー
- [ ] チーム内で 15分の振り返り（Slack スレッドでも可）

---

## Day 60-90（運用フェーズ）

公開30日を超えたら、運用契約 or 追加プロジェクトのフェーズへ。

- 月次運用レポート（GA4 / GSC / Lighthouse）
- 月1回のクライアントMTG
- 軽微な追加コンテンツ・修正
- 大規模改修は別案件として見積・契約
